# 🚀 Yogyata  Resume & Skill Matcher

An AI-powered Resume & Skill Matcher web application built using Django.  
This platform helps users compare their skills with job requirements and get an instant match percentage along with career suggestions.

---

# 🌟 Features

✅ User Registration & Login  
✅ Secure Authentication System  
✅ Skill Matching System  
✅ Match Percentage Calculation  
✅ Missing Skills Detection  
✅ Career Suggestions  
✅ Resume Strength Analyzer  
✅ Previous Analysis History  
✅ Modern Attractive UI  
✅ Responsive Design  
✅ Dashboard Cards & Progress Bar

⚙️ Installation Process

1️⃣ Clone Repository
git clone https://github.com/RAUNAKSHUKLA9939/yogyata-resume-skill-matcher.git

2️⃣ Open Project Folder
cd yogyata-resume-skill-matcher

3️⃣ Create Virtual Environment
python -m venv venv

4️⃣ Activate Virtual Environment
Windows
venv\Scripts\activate
Linux / Mac
source venv/bin/activate

5️⃣ Install Requirements
pip install -r requirements.txt

6️⃣ Run Migrations
python manage.py makemigrations
python manage.py migrate

7️⃣ Start Server
python manage.py runserver

🌐 Open In Browser
http://127.0.0.1:8000/

🧠 How It Works
User enters personal skills.
User enters:
Job Role
Company Name
Required Skills
System compares skills.
Match percentage is calculated.
Missing skills are shown.
Career suggestions are generated.
Analysis history is saved.

📊 Match Calculation Logic
match_percentage = (
    matched_skills / total_required_skills
) * 100
